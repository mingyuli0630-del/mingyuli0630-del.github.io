# 李明諭個人網站｜V28 多頁版

這一版已改為真正的多頁網站，不再用同一份 HTML 隱藏其他區塊。

## 頁面
- `index.html`：首頁／教學框架／教學經歷／課堂紀錄
- `about.html`：關於我／教學觀／履歷產生器
- `resources.html`：公開教材
- `career.html`：數學教師職涯參考
- `courses.html`：課程與收費
- `404.html`：找不到頁面
- `style.css`：全站共用樣式
- `script.js`：全站共用互動與資料
